# VideoPairing

VideoPairing 是一款用于 **剪映/CapCut草稿自动化处理** 的工具，主要用于短视频配音和视频时间轴对齐。

支持：

- 🎬 视频与配音自动对齐
- 🎤 Edge TTS / Fish Audio 配音
- 📝 字幕提取与字幕处理
- 🔇 音频停顿处理
- 🎞️ 视频变速与智能补帧
- 🧩 自动创建复合片段
- ↩️ 对齐操作撤回
- ⚙️ 批量字幕处理

适合 **TikTok、YouTube Shorts、影视解说、多语言配音、AI 配音短视频** 等制作场景。

简单来说：

**字幕 → 配音 → 自动调整视频 → 写回剪映草稿**
