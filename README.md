# VideoPairing

**面向剪映 / CapCut 的字幕、翻译、配音与草稿自动化工具。**

VideoPairing 将字幕提取、AI 改写翻译、语音生成、草稿创建和视频对齐串成连续流程，减少逐条配音、调整时间轴和整理素材的重复操作。适合影视解说、短视频、多语言配音、TikTok 和 YouTube Shorts 等制作场景。

[项目主页](https://github.com/NoIdea2333/VideoPairing-Update) · [问题反馈](https://github.com/NoIdea2333/VideoPairing-Update/issues)

> 本仓库用于 VideoPairing 的软件介绍、更新说明与公告维护。具体功能以安装版本为准。

## 从视频到可编辑草稿

```text
视频 / 音频
    ↓
提取字幕 → AI 改写与翻译 → Edge TTS / Fish Audio 配音
    ↓
创建剪映 / CapCut 草稿 → 对齐视频与配音 → 在编辑器中检查并导出
```

各功能也可以独立使用：已有字幕可直接翻译或配音，已有草稿可直接进行对齐与字幕处理。

## 主要功能

### 字幕提取与处理

- 批量提取视频、音频中的字幕，支持 SRT 和 TXT 输出。
- 可关联翻译与草稿创建，减少跨页面手动导入。
- 支持字幕间隙桥接、短行合并、自动分割和符号处理。
- 可从已有草稿导出字幕，并按视频分别导出。

### AI 改写与翻译

- 支持改写、翻译以及单阶段、整篇等处理方式。
- 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini 接口协议。
- 可配置接口地址、模型、API Key 和自定义请求头。
- 支持目标语言、提示词预设和文件并发设置。
- 翻译接口默认可使用改写页参数，也可单独配置。

### 配音生成

- 支持 **Edge TTS** 与 **Fish Audio**。
- 支持批量字幕配音、音色选择、语速及间隙调整。
- Fish Audio 支持多账号轮替或并行处理，以及支持模型的情绪标签。
- 可复用有效音频缓存，继续处理未完成任务。

### 草稿创建与视频对齐

- 根据视频和字幕创建剪映 / CapCut 可编辑草稿。
- 支持每个视频单独创建草稿，或按文件夹合并创建。
- 按配音与字幕调整视频时间轴，支持变速、补帧、音量和复合片段处理。
- 支持字幕样式、自定义预设和画面效果设置。
- 待对齐与已对齐分区显示，完成后自动切换分类。
- 支持对齐操作撤回。

### 智能封面

- 自动选择清晰人物画面，支持刷新候选与封面预览。
- 支持男女及儿童、青年、中年、老年人物外观筛选。
- 提供 **头像到肩部、头像到胸口、半身** 三种构图。
- 支持封面标题、画布适配，以及更换已创建草稿的封面。

人物年龄和构图根据画面估计；原视频缺少相应身体区域时，无法补出画面外内容。未找到可靠人物候选时，会回退自动选帧。

## 连续任务与异常提示

开启关联后，单视频翻译完成即可进入创建队列，翻译和创建可以同时进行。按文件夹合并草稿时，需要收齐该批对应字幕后再创建。

任务失败或停止后，可在翻译页或创建页继续处理，相关状态同步回字幕提取页。提取、翻译和配音遇到网络错误、超时、限流或服务异常时，会显示原因及重试提示，方便及时检查网络或代理。

## 使用步骤

1. 按软件提示完成授权，选择剪映或 CapCut 草稿目录。
2. 导入视频、音频或已有 SRT 字幕。
3. 按需要开启关联翻译、创建草稿，并配置翻译接口和配音音色。
4. 运行任务，查看任务状态；失败或停止后可继续处理。
5. 对创建好的草稿进行视频对齐，再回到剪映 / CapCut 检查效果并导出。

修改、对齐、撤回或更换已有草稿封面前，请先关闭编辑器中正在打开的对应项目，避免自动保存覆盖处理结果。

## 设置保存与更新

支持集中存储的版本将用户设置保存至：

```text
%APPDATA%\VideoPairing
```

包含软件设置、翻译接口配置、音色设置、授权文件，以及自定义预设、参数组合、画面效果和字体库。缓存与输出文件按各自用途保存。

- 普通设置改动后自动保存，减少异常退出造成的设置丢失。
- **命名参数组合仍需手动点击保存**，不会因调整当前选项而自动覆盖。
- 首次运行自动导入旧用户目录及当前软件目录中的旧数据，保留原文件，不覆盖新目录已有设置。
- 完成迁移后，移动软件目录或重新解压新版不会删除固定用户目录中的设置。

**首次迁移前请保留旧版数据。** 若更新前已删除保存旧设置的程序目录，该部分数据无法自动恢复。默认允许本机明文保存接口密钥和请求头，可在翻译设置中取消勾选；反馈问题时不要上传含密钥的配置文件。

## 常见问题

**任务长时间没有进度怎么办？**

先查看任务状态和日志。网络错误或超时提示出现时，检查网络、系统代理及接口地址；限流时可降低并发或等待服务恢复。必要时停止任务，修正设置后继续处理。

**翻译、配音需要额外配置吗？**

AI 翻译需要可用的文本模型接口。Fish Audio 需要相应 API Key 和音色配置；第三方服务的费用、额度与可用性由服务商决定。Edge TTS 也需要正常的网络连接。

**软件会直接导出最终视频吗？**

主要产物是字幕、配音及可编辑草稿。完成处理后，在剪映 / CapCut 中检查并导出最终视频。
